# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
**Security tab > Report a vulnerability** on <https://github.com/Mosberg/bluehour-vr>.

Include what you found, how to reproduce it, and which version you used. You will get a first reply within
seven days. Bluehour opens local USB and Bluetooth HID devices and plays media files and URLs through libmpv,
so reports about file or URL handling and device access are the most relevant.
