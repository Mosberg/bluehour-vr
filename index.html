Bluehour

Watch movies and VR video on your Oculus Rift DK2 again, without any Oculus software.

Set up Bluehour View on GitHub
pip install git+https://github.com/Mosberg/bluehour-vr.git

What you get

Flat, curved and VR video
A cinema screen in front of you, or VR180 and VR360 all around you, with mono, side-by-side and over-under 3D. Bluehour reads the layout from the file name.
Made for the DK2 lenses
Lens distortion and colour fringing correction that you can tune while you watch.
Head tracking without the runtime
Rotation comes straight from the headset's sensor over USB. Lean and move using the DK2 camera or a Wii Remote's IR camera.
Any controller
Keyboard, Wii Remote, or a USB gamepad: Xbox One, PS3, or a raphnet adapter for Classic controllers, Nunchuks and guitars.
Plays almost any file
Decoding, audio, subtitles and web addresses come from libmpv.

Where it stands

Alpha. Not yet tested on a real DK2.

The maths, sensor decoding, Wii Remote protocol and gamepad logic are covered by automated tests. Lens values, axis directions and camera behaviour may need tuning on your headset, and the guides show how.

If you have a DK2, the hardware checklist takes about ten minutes and helps more than anything else.

Start in four steps

  1. Install Python 3.9 or newer and libmpv. On Windows put libmpv-2.dll in the folder you run Bluehour from.

  2. Plug the DK2 into your graphics card and USB, make it an extended monitor, and set it to 1920x1080 at 75 Hz.

  3. Install Bluehour and check that it sees the headset.

    pip install git+https://github.com/Mosberg/bluehour-vr.git
bluehour --list-monitors

  4. Play something.

    bluehour movie.mp4
bluehour --proj vr180 --stereo sbs clip.mp4
bluehour --windowed movie.mp4   # preview without a headset
